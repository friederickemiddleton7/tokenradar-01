**Token Radar** ranks 200 pre-token protocols by an implied value measured from the snapshot's own market: each protocol is priced at the median market-cap-to-TVL of the live protocols in its category, then adjusted for seven-day momentum and for how long it has run with no token. Every row carries a concrete, costed, timed farm plan. The dashboard is a static page with a sortable board, a per-protocol detail view and a filtered view.

## Run it

```sh
node --experimental-strip-types main.ts --input /input/snapshot.json
```
